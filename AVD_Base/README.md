# Ekco Cloud Desktop Base

This module is used to deploy the base resources for Ekco Cloud Desktop. By base resources, we mean the Storage Account, the Load Balancer, the Public IP Address, and Resource Groups.

## Template Spec

Use the button below to deploy this pattern from the public GitHub repository with its custom form:
